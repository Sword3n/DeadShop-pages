# DeadShop — the built site

This repository holds the **built** DeadShop site — the files a visitor
downloads. It is published automatically from the private source
repository `Sword3n/DeadShop-site` and is rewritten on every push.

The source, the build tools, the test suite and the history live in the
private repository and are not published here.

source repository.
